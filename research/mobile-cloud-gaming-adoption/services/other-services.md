## Steam Link (Steam Remote Play)

### Key Statistics
- **User Base**: Not disclosed by Valve
- **Steam Total MAU**: 132 million (2024) - overall Steam platform
- **Remote Play Together**: Feature available, usage % unknown
- **App Reviews**: 73% positive (3,686 reviews)

### Mobile Support
- **Android**: Steam Link app available on Google Play
- **iOS**: Steam Link app available on App Store
- **Recent Updates**: HDR streaming (2024), 4K support (2023)

### Platform Distribution
❌ **No Remote Play usage statistics publicly disclosed by Valve**

### Characteristics
- **Model**: Local streaming (from your own PC to mobile, not cloud servers)
- **Distinction**: This is **Remote Play** (like PS Remote Play), not true cloud gaming
- **Cost**: Free (requires owning a gaming PC and games)
- **Use Case**: Play PC games in other rooms or away from home

### Mobile MAU Estimation
**Challenge**: Valve doesn't disclose Steam Link/Remote Play usage

**Indirect Indicators**:
- Steam has 132M MAU
- If 5-10% use Remote Play: ~6.6-13.2M
- If 25% of Remote Play is mobile: ~1.6-3.3M
- **Estimated Mobile MAU**: **~2-4M** (very rough estimate)

**Confidence**: VERY LOW - purely speculative, no official data

## Shadow

### Key Statistics
- **Subscribers**: Not publicly disclosed
- **Pricing**: $32.99/month (US), £32.99/month (UK)
- **Service Type**: Full Windows PC in the cloud (not game streaming)

### Model Distinction
⚠️ **Shadow is NOT a game streaming service**
- Provides a full virtual Windows PC
- Users install their own games
- More expensive than game streaming services
- Competes more with gaming PCs than with GeForce Now/Luna

### Mobile Support
- **Technically**: Can access Shadow PC from mobile
- **Practically**: Not optimized for mobile gaming (full desktop interface)

### Mobile MAU Estimation
Given the service model and price point:
- **Estimated Total Users**: ~50-100K (rough estimate, niche market)
- **Mobile Usage**: Minimal (not designed for mobile)
- **Estimated Mobile MAU**: **<10K** (negligible)

**Confidence**: LOW (no data, service not mobile-focused)

## Key Insights

### Market Structure
1. **Big 3 Dominate**: Xbox, PlayStation, GeForce Now have 80-90% of mobile cloud gaming
2. **Regional Players Matter**: Boosteroid (Europe), Netboom (Asia) have regional strength
3. **Long Tail**: Dozens of small services with <100K users each

### Mobile Prioritization
- **Mobile-First**: Netboom, some Asian services
- **Mobile-Supported**: Luna, Boosteroid, most major services
- **Desktop-First**: GeForce Now, Shadow, Steam Link

### Business Model Variance
- **Subscription**: Luna, Boosteroid, Shadow (most common)
- **Freemium**: GeForce Now (free tier + paid)
- **Free**: Steam Link (requires owning PC and games)
- **Full PC**: Shadow ($33/month, high-end)

### Geographic Patterns
- **US-Focused**: Amazon Luna (US-only for years, limited expansion)
- **Europe-Strong**: Boosteroid (6M+ in Europe)
- **Asia-Pacific**: Netboom, regional services
- **Global**: Steam Link (wherever Steam exists)

## Challenges in Estimating "Other Services"

### 1. Lack of Disclosure
- Most smaller services don't publish user numbers
- Private companies have no obligation to report
- Competitive reasons to keep data private

### 2. Definition Issues
- What counts as "cloud gaming"? (Steam Link is remote play, not cloud)
- Shadow is a cloud PC, not game streaming
- Beta services, mobile game streaming (Google Play Games), etc.

### 3. Regional Fragmentation
- Asia has many services unknown in the West
- Latin America, Middle East have regional players
- Can't comprehensively track all services

### 4. Download ≠ Active Users
- App stores show downloads, not MAU
- Free services may have high churn
- "Registered users" vs "monthly active users"
