## Quick Status Check

To verify current status, run:
```bash
# Check if environment is set up
ls -la venv/

# Check database
sqlite3 data/articles.db "SELECT COUNT(*) FROM articles;" 2>/dev/null || echo "DB not yet created"

# Check articles scraped
sqlite3 data/articles.db "SELECT COUNT(*) FROM articles WHERE scraped_at >= date('now');" 2>/dev/null || echo "No articles today"

# Check images
ls images/$(date +%Y-%m-%d)/ 2>/dev/null | wc -l || echo "0"

# Check scheduler
ps aux | grep scheduler | grep -v grep || echo "Scheduler not running"
```
